# 公开仓库范围

本仓库从 AIStudio 的当前源码导出，使用新的 Git 历史，保留原始来源提交和文件哈希。原工作台及其完整本地历史保持原样。

包含：自编写工作流脚本、Unity Editor/Runtime 测试代码、Unity 依赖与渲染设置、工具策略、配置样例、脱敏历史验证摘要。

新增 UE5 部分包含适配脚本、`.uproject`、默认 `.ini` 和脱敏验证摘要。生成的地图、导入后的资产、SDK/引擎文件、缓存和打包文件留在本地。`source-export.json` 对应首次公开导出的来源快照；后续功能变更通过 Git 提交追踪，不用旧哈希代替当前文件校验。

排除：模型权重、Mixamo FBX、Fab/Epic/Asset Store 原包及其内容、混元生成/派生的网格与纹理、受限展台画面、账号资源收藏清单、缓存、运行进程记录、日志、真实本机路径、凭据、旧 Git 历史和构建包。模型或素材的本地验证状态不作为公开分发依据。

`Registry/asset-manifest.json` 和 `fab-catalog.json` 是新的空登记表。不能把原机已拥有或验证过的素材状态自动带给仓库使用者。取得自己可用的素材后，在本地登记再调用准入工具。

Unity 包由 Package Manager 根据依赖清单安装，没有把依赖的实现源码复制进仓库。第三方软件与素材仍遵循各自条款；仓库未为这些内容授予新许可。
